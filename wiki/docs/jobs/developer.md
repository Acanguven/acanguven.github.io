# Developer

The **developer** track is the flagship **tech career**: strong late-game pay, **programming**-gated promotions, and **computer literacy** as the foundation. It expects you to invest **time and tuition** before the job feels “easy.”

## Key skills

- **Basic computer** — entry literacy; trained by the first software course wave.
- **Programming** — the real ladder stat; university-tier education pushes it higher.

:::tip
Start **software development (apprenticeship)** as soon as age and money allow. The **university** programming course **requires** that first program—skipping it blocks the entire senior path.
:::

## Education gates

Unlike bartending or waitressing, developer ranks assume **sequential courses**:

1. Apprenticeship-style **software engineering** track (computer skill, many in-game days).
2. College-category **advanced software / programming** track chained after the first completion.

Treat tuition as **startup capital**: a few months of teen work funds the first course if you budget.

## Interviews

Tech hiring uses a dedicated **interview pool**—expect logic, ethics, and stress questions. **Intelligence** helps learning speed globally, so academic characters promote faster with fewer calendar days.

## Strategy

- Run **school courses** or **digital marketing** (computer-adjacent) if you need a cheaper bridge before formal dev tuition.
- Avoid burning out: low **energy** tanks interview performance indirectly through missed days.
- Pair with **banker** only if you love spreadsheets—both want calendar time.

:::tip
If your goal is **maximum income per year played**, developer is a marathon: commit or pick **delivery** or **banker** for a shorter ramp.
:::
