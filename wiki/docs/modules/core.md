# Core module

The **core** package is the **default game**: every player has it. It defines the ordinary life arc — school, jobs, housing, romance, aging, economy, diseases, travel, and the bulk of quests unrelated to crime, fame, or monsters.

## What core covers

| Pillar | Examples |
| --- | --- |
| **Careers** | Service jobs, office paths, trades, education gating |
| **Locations** | Home, city services, shops, school, hospital, witch house, etc. |
| **Stats** | Intelligence, looks, and the shared skill / need systems |
| **Social** | Family, love, friends, coworkers — see **[Social interactions](../social/interactions)** |
| **Health** | Health / energy / morale, diseases, hospital treatment |
| **Economy** | Money, market, rent, furniture |

:::info
Think of **core** as the **simulation chassis**. Optional modules bolt **crime**, **celebrity**, and **monster** arcs onto the same character sheet.
:::

## Why it matters for module buyers

Even with every DLC active, you still:

- Pay **rent**, work **jobs**, and manage **needs**
- Use **hospital** (or witch) for disease — prison clinic reuses doctor action when jailed
- Progress **generic achievements** and tutorials

:::tip
Strong **core** fundamentals (stable job, health buffer, savings) make **crime** or **hunting** side paths less run-ending when they punish you.
:::
