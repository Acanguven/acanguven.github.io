# Crime module

The **crime** pack turns **Life Simulator Reloaded** into a crime drama when you want it: steal, smuggle, forge, run from police, and — if caught — play a whole second phase inside **prison**.

## Major systems

| System | What you’ll notice |
| --- | --- |
| **Crime actions** | Pickpocketing, vehicle theft, smuggling, forgery, and more |
| **Wanted** | A timer that stacks; police can interrupt you when you travel |
| **Prison** | Its own **area**, locations, a daily prison-life skill, and random events |
| **Prison reputation** | A stat that matters mainly while you are sentenced |
| **Fights** | Prison-only combat against other **prisoners** |
| **Items** | Contraband, improvised weapons, blueprints, luxury prison loot |

:::warning
Going to prison usually **forces you to quit** normal jobs and can **remove prison-tagged items** when you get out. Plan for that reset.
:::

## Content depth

- **Mini-games:** memory challenges, timing and focus trials, crafting and smuggling sequences, training mash-style tasks, riot-style target rounds, plus more tied to random events (parole hearings, shakedowns, and similar beats).
- **Interactions:** greet, intimidate, trade, share meals, gossip, ask for protection, fight, defend a friend, steal, extort, recruit for a gang, bribe a guard.
- **Quests:** long arcs like Survivor, Scholar, and Kingpin — see **[Prison quests guide](../crime/prison-quests-guide)**.
